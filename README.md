# DataCon25 — Анализ молекулярных данных

## 📌 Описание проекта

Проект выполнен в рамках соревнования [DataCon25](https://github.com/AsyaOrlova/DataCon25), посвящённого применению методов анализа данных и машинного обучения для задач химии и фармацевтики. Основная цель — предсказать биологическую активность молекул на основе их структуры (SMILES) и рассчитанных дескрипторов.

## 📁 Структура проекта

```
├── data/               # Исходные и обработанные датасеты
├── notebooks/          # Jupyter-ноутбуки с анализом и моделированием
├── models/             # Сохранённые модели и результаты обучения
├── results/            # Графики, таблицы метрик, submission-файлы
└── main.py             # Основной запускной скрипт (при наличии)
```

## 📊 Используемые данные

- Формат: `.csv`
- Основные поля:
  - `SMILES` — строковое представление молекулы
  - `IC50`, `standard_value` — биологическая активность
  - Дескрипторы молекулы
- Дополнительные преобразования:
  - Преобразование значений активности к единой шкале (nM)
  - Фильтрация невалидных SMILES с помощью `RDKit`

## 🔍 Этапы работы

1. **Предобработка данных**
   - Очистка пропущенных и некорректных значений
   - Проверка валидности SMILES
   - Удаление дубликатов

2. **Формирование признаков**
   - Расчёт молекулярных дескрипторов (`rdkit.Chem.Descriptors`)
   - Построение фингерпринтов (ECFP, MACCS и др.)
   - Нормализация/стандартизация признаков

3. **Обучение моделей**
   - Используемые алгоритмы:
     - Random Forest
     - Gradient Boosting
     - Ridge Regression
   - Кросс-валидация
   - Поиск лучших гиперпараметров

4. **Оценка качества**
   - Метрики: MAE, RMSE, R²
   - Визуализация предсказаний против истинных значений

## 💡 Выводы

- Самыми информативными признаками оказались: молекулярный вес, количество водородных доноров, логP.

- Качество модели ограничено разнородностью исходных данных.
